# C++ 中高级选择题备考

本目录用于准备以选择题为主的 C++ 中高级能力测试。

## 语义基线

除非题目特别说明，默认按 **C++17** 语言规则理解；题目重点覆盖 C++11/14/17 中已经非常稳定、且在中高级笔试中高频出现的语言特性。

## 第一阶段：高频考点

1. 函数重载、默认参数、名字隐藏、`const` 重载
2. 类与对象、构造/析构、初始化顺序、拷贝/移动语义
3. 继承、虚函数、动态绑定、对象切片、虚析构
4. 指针、引用、`const`、生命周期、左值/右值
5. 模板、`auto`、`decltype`
6. STL 容器、迭代器失效、`map`/`unordered_map`、算法比较器
7. 智能指针、RAII、异常安全
8. 运算符重载、RTTI、`dynamic_cast`、常见未定义行为

## 建议做题方式

第一遍先只看题目并记录答案；第二遍展开“答案与解析”，重点记录自己错在：

- 规则不知道；
- 规则知道但调用顺序判断错；
- 静态类型 / 动态类型混淆；
- 编译期行为 / 运行期行为混淆；
- 生命周期或资源所有权判断错误。

后续可以继续按错题分布追加专题卷，例如：`virtual-and-inheritance.md`、`constructor-lifetime.md`、`stl-traps.md`。
