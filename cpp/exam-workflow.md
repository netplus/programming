# C++ 中高级选择题备考流程

## 目标

面向中高级 C++ 选择题考试，通过小批量模拟题持续暴露薄弱点，并把错题沉淀成可复习的专题材料。

## 训练循环

1. 每轮给出 5～10 道单选题，不提前显示答案。
2. 用户按 `1A 2C 3B ...` 的格式提交答案。
3. 对每道题逐题复盘：
   - 正确答案；
   - 关键语言规则；
   - 为什么其它选项错误；
   - 常见误判路径；
   - 考试时的快速判断方法。
4. 根据错题动态调整下一轮：
   - 同类知识点提高权重；
   - 由直接规则题逐步升级为组合陷阱题；
   - 已稳定掌握的知识点降低重复频率。
5. 每完成若干轮，将高频错题和关键规律整理成专题卷或新的模拟卷。

## 当前语义基线

默认使用 C++17 规则，除非题目明确说明其它标准版本。

## 重点考点

- 函数重载、默认参数、名字查找、`const` 重载；
- 构造函数、析构函数、拷贝/移动语义、对象生命周期；
- 继承、虚函数、动态绑定、虚析构、对象切片；
- 引用、指针、值类别、`auto`、`decltype`；
- 模板参数推导与转发引用；
- STL 容器、迭代器失效、算法比较器；
- 智能指针、RAII、RTTI。

## 复盘原则

优先按以下顺序判断题目：

1. 这是编译期规则还是运行期行为；
2. 静态类型和动态类型分别是什么；
3. 对象是否仍然处于有效生命周期；
4. 是否发生隐式转换、名字隐藏或对象切片；
5. 是否存在未定义行为或编译错误。
